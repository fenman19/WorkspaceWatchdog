Guided installation
  1. Activate the license from your welcome email.
  2. Add optional reputation/geolocation keys.
  3. Connect a Google Cloud project, enable Admin SDK API and Apps Script API, and allow Apps Script API access.
  4. Test both Google Workspace APIs. Use the repair links only if a test fails.
  5. Run Fast Install, then run the Final Health Check.

Step 3 — Google Cloud & OAuth Setup ▼
Required before the first install and for repository updates.
Create this project while signed in as a Google Workspace administrator for the organization installing Workspace Watchdog. Use an Internal OAuth audience so the app remains limited to that organization and does not require public Google verification.
1
Create a new Google Cloud project
  1. Open Manage Resources and click Create Project.
  2. Name it Workspace Watchdog or Workspace Watchdog - Your Organization.
  3. Select your organization's Google Cloud organization and an appropriate folder, if prompted.
  4. Click Create, then select the new project from the project selector at the top of the Cloud Console.
2
Configure the OAuth consent screen
  1. Open Google Auth Platform and click Get Started if this project has not been configured.
  2. For App name, enter Workspace Watchdog.
  3. Select an administrator email for User support email.
  4. For Audience, select Internal. Do not select External for a customer-owned installation.
  5. Enter an administrator or IT support address under Developer contact information.
  6. Complete the setup. A logo, homepage, privacy policy, and terms links are optional for an internal-only customer project.
Do not create an OAuth client ID. Apps Script manages its own OAuth authorization for this bound script.
3
Confirm OAuth data access
Apps Script normally derives these permissions from appsscript.json. In Google Auth Platform → Data Access, add or confirm the following scopes if Google asks you to configure them:
https://www.googleapis.com/auth/admin.directory.user.readonly
https://www.googleapis.com/auth/admin.reports.audit.readonly
https://www.googleapis.com/auth/script.container.ui
https://www.googleapis.com/auth/script.external_request
https://www.googleapis.com/auth/script.scriptapp
https://www.googleapis.com/auth/script.projects
https://www.googleapis.com/auth/spreadsheets
https://www.googleapis.com/auth/userinfo.email
https://www.googleapis.com/auth/gmail.send
https://www.googleapis.com/auth/gmail.compose
https://www.googleapis.com/auth/gmail.modify
https://www.googleapis.com/auth/gmail.addons.current.action.compose
These scopes support audit reporting, directory lookups, spreadsheet access, repository updates, and optional email features. Because the OAuth audience is Internal, authorization is limited to users in the customer's Workspace organization.
4
Enable the required APIs
  1. Open Admin SDK API and click Enable.
  2. Open Google Apps Script API and click Enable.
  3. Open Apps Script Dashboard Settings and turn on Google Apps Script API access for your account.
5
Attach the Cloud project to this Apps Script project
  1. In Google Cloud, open IAM & Admin → Settings and copy the numeric Project number. Do not copy the Project ID.
  2. Open Apps Script Project Settings.
  3. Under Google Cloud Platform (GCP) Project, click Change project.
  4. Paste the Project number and save.
  5. Accept any authorization prompt, then reload this spreadsheet.
6
Verify the connection
  1. Return to this wizard.
  2. Run Test Both in Step 5.
  3. If both tests pass, continue with Fast Install or Install / Repair.
Important: Changing the associated Cloud project invalidates the previous authorization. A new authorization prompt is normal.
Step 4 — Full Screen Map Access ▼
Optional feature. Install the dashboard first. To enable the full-screen map:
  1. Open Deployments and create a Web App deployment.
  2. Choose Execute as: User accessing the web app.
  3. Copy the deployment ID, then open Apps Script Project Settings and add it to Script Properties as DEPLOYMENT_ID.
  4. Return here, save allowed users, and click Show Map URL.
Step 5 — Install / Repair ▼
First time? Click Install / Repair to create all sheets, set up triggers, and run the first sync. Use Fast Install to seed with fewer hours of history. Run Install / Repair anytime to fix missing triggers or sheets without losing data.
